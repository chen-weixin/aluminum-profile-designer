# 路线图

## v0.1 PWA 可用原型

- 建立 `pwa/` 静态应用。
- 实现参数化框架生成。
- 内置 `2020`、`3030`、`4040` 型材。
- 支持角码、内置连接件、端面连接件的基础扣减规则。
- 实现 Canvas 轴测预览。
- 输出下料清单、连接件、螺丝和基础成本估算。
- 支持 localStorage 本地保存。
- 支持 JSON 导入导出和 CSV BOM 导出。
- 支持 manifest 和 service worker。

## v0.2 手机体验优化

- 优化触屏点选构件。
- 增加项目复制、重命名和删除。
- 增加尺寸标注层。
- 增加常用模板：工作台、置物架、设备架、鱼缸架。

## v0.3 精准算料增强

- 增加更多连接件规则。
- 增加损耗率、整根料长度和拼料建议。
- 增加基础报价单。
- 增加导出 PDF 或打印样式。

## 暂不纳入第一版

- 自由 CAD 建模。
- 斜撑和异形角度。
- 板材、台面、门板计算。
- 开孔加工图。
- 账号、云同步、多人协作。
